## 설명 (Description)

```
둥실은 숫자와 기록보다 "오늘 물속에서 어땠는지"를 남기는 감성 수영 다이어리예요.

🌊 캘린더
오늘의 수영을 기분·종목·거리·시간과 함께 기록하고, 달력으로 한눈에 돌아보세요.
애플 건강(HealthKit) 연동으로 운동 기록을 자동으로 불러올 수 있어요.

📍 가이드
- 수영장 찾기: 행정안전부·서울 열린데이터광장 공공데이터 기반, 전국 수영장의 운영시간·
  요금·레일 수·자유수영 안내까지 실제 정보로 확인하고 지도에서 바로 찾아가세요.
- 자유게시판: 수영 이야기를 자유롭게 나누세요.
- 자유수영: 자유수영 시간 정보를 모아봤어요.

🏊 수친
연락처 기반으로 수영 친구를 찾고, 수톡(오픈채팅)과 톡톡(수영 모임)으로 소통하세요.

🎬 티칭
수영 관련 인기 영상을 매일 아침·저녁 새로 모아 보여드려요.

로그인은 Apple 계정만으로 간편하게, 불필요한 개인정보는 요구하지 않아요.
```
