# 둥실곰 이미지 규칙

## 구조
- 서 있는 곰(정면)은 **기준 곰 한 장 + 아이템 레이어**를 같은 크기 캔버스에 겹쳐 그린다. (`src/components/bear/BearSprite.tsx`)
  순서: 기준 곰 → 수영복 → 메달 → 수모 → 수경. 아이템은 서로 독립이라 마음대로 켜고 끈다.
- 레이어는 모두 432×724 PNG(투명 배경), 같은 자름·같은 배율이라 겹치기만 하면 맞는다. 곰 몸은 한 장이라 아이템을 바꿔도 몸이 변하지 않는다.
- 헤엄 곰은 아직 옛 그림(`assets/bear/swim-*.png`)이다. 새 곰의 헤엄 그림(아이템별)이 준비되면 교체한다.

## 만드는 방법
캐릭터 스튜디오(ChatGPT) 결과물을 `design-drops/` 에 두고 `python3 scripts/build-bear-layers.py` 를 실행한다.
(opencv-python, numpy 필요) 기준 곰과 착용본의 차이만 오려서 `assets/bear/front-*.png` 를 만든다.

## 크기·위치 고정 규칙
수모·수경·원피스·숏사각·메달의 **크기와 위치는 바뀌지 않는다.** 앞으로 바뀌는 것은 디테일 디자인(무늬, 색, 재질)뿐이다.
- 기준값은 `design-drops/front-layout.json` (원본 1024×1536 좌표의 아이템 영역).
- 새 그림이 이 값에서 8px 넘게 벗어나면 스크립트가 멈추고 알려준다. 의도한 변경이면 `--accept`.
- 새 디자인은 항상 기준 곰(`char_bear__front__base__v1.png`) 하나만 편집해서 만든다. (아이템을 여러 개 한꺼번에 입힌 그림은 쓰지 않는다.)
